Aspectos Técnicos del TPI implementados

1. Normalización 3FN & Herencia

Tabla base Personas vinculada a Socios y Empleados mediante FK explícitas, evitando redundancias y duplicación de datos de contacto.

2. Triggers DML con Atomicidad

trg_Inscripcion_ActualizarCupo decrementa cupos y cancela con ROLLBACK si el salón está lleno. trg_Cancelacion_ActualizarCupo devuelve la vacante.

3. Transacciones ACID

sp_RegistrarPagoMembresia ejecuta bloques BEGIN TRANSACTION / COMMIT / ROLLBACK con control estructurado TRY...CATCH y RAISERROR.

4. Acceso Eficiente en C#

Uso de Dapper con streaming asincrónico (await using, consultas parametrizadas contra inyecciones SQL y DTOs inmutables con Records).
